# Hotel Reservation System (HRS)

This project is a simple Hotel Reservation System written in C++.  
It includes room listing, booking, and other features for managing hotel operations.

## Files
- `HRS.cpp`: Source code
- `HRS.exe`: Executable file

## How to Run
1. Compile `HRS.cpp` using any C++ compiler.
2. Or run `HRS.exe` directly (Windows only).
